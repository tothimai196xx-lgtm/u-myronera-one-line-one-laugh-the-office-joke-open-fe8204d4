## What it does

`main.ts` writes a single original one-line joke about office life to
`/output/entry.txt`. The joke is 191 characters long (limit: 1–200), built
around one concrete image — the office fridge — with the punchline landing
in the last few words.

## Run

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22.18 or later.
